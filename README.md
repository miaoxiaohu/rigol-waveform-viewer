# RIGOL 波形查看器 · rigol-waveform-viewer

> 单文件、零依赖的 RIGOL 示波器 `.bin` 波形查看器。双击 `index.html` 就能用，不需要装任何东西，也不需要连着示波器。

## 为什么做这个

RIGOL 示波器可以把采集到的波形存成 `.bin`。但官方的查看器要么要连着仪器、要么只在 UltraVision 里能用；想把一段波形发给同事看，或者归档几个月前抓到的故障波形，都不太方便。

这个工具把 `.bin` 直接丢进浏览器就能看：**没有服务器、没有依赖、没有构建步骤，文件也不会离开你的机器。**

## 特性

- **零依赖、零构建**：整个应用就是一个 `index.html`，`file://` 直接打开就能跑。
- **支持三种格式**：`RG01` / `RG02` / `RG03`，覆盖 DS1000Z、MSO5000、DS7000、DHO800、DHO1000、DS8000、MSO8000 等系列。
- **百万点流畅**：用 LTTB（Largest-Triangle-Three-Buckets）降采样，保留尖峰和波形形状，不会把毛刺抹平。
- **多通道同步**：所有通道共享同一个时间窗口，缩放 / 平移完全对齐，可以直接做通道间时延对比。
- **框选即测量**：左键拖一个区间 → 自动设成 T1/T2 光标；右键拖一个区间 → 放大到那块区域。
- **统计跟着窗口走**：右侧的 min / max / 峰峰 / 均值 / σ 统计的是**当前可见窗口**，不是整段记录 —— 放大到毛刺上看噪声，这个数才是有意义的。
- **逐通道光标读数**：T1/T2 处每个通道的电压值和 ΔV 一览。
- **自适应时间轴**：放大之后刻度的小数位会自动变细，不会出现五个一模一样的 `0.00 ms`。
- **通道显隐**：点底部图例即可开关某个通道。
- **完全本地**：所有解析都在浏览器里完成，`.bin` 不会被上传到任何地方。

## 快速开始

```bash
git clone https://github.com/miaoxiaohu/rigol-waveform-viewer.git
cd rigol-waveform-viewer
```

直接用浏览器打开 `index.html`，把 `.bin` 拖进去就行。

没有示波器也想先看看效果？仓库里带了一个生成器，可以造一个格式完全正确的合成波形：

```bash
node tools/make-sample-bin.js        # 生成 sample/DHO814_demo.bin
node tools/verify-sample.js          # 用 index.html 里的解析器验证它能被正确读取
```

> `tools/verify-sample.js` 是把 `index.html` 里的解析器原样抠出来跑的 —— 所以「生成器」和「查看器」对格式的理解一定是一致的，改了一个忘了改另一个，测试会立刻报错。

## 操作方式

### 鼠标

| 操作 | 效果 |
| --- | --- |
| 左键拖拽 | 框选时间区间 → 自动设成 T1/T2 光标 |
| 右键拖拽 | 框选矩形 → 放大到该区域 |
| 中键拖拽 / `Shift` + 左键 | 平移波形（所有通道同步） |
| 滚轮 | 以当前视图中心缩放 |
| 拖拽顶部三角手柄 | 微调 T1 / T2 光标位置 |
| 点击底部图例 | 显示 / 隐藏该通道 |

### 键盘

| 按键 | 效果 |
| --- | --- |
| `F` | 恢复完整波形显示 |
| `C` | 启用 / 关闭 T1-T2 光标 |

> 统计与测量都基于**当前可见窗口**。时间轴是相对时间，可见窗口的最左端恒为 `0`。

## 支持的文件格式

`.bin` 是私有格式，没有公开文档。下面的布局是逆向出来的，也是本工具解析所依赖的全部信息：

**文件头（固定 128 字节）**

| 偏移 | 长度 | 含义 |
| --- | --- | --- |
| `0x00` | 4 B | 文件标识 cookie：`RG01` / `RG02` / `RG03` |
| `0x04` | 4 B | uint32，文件总长度 |
| `0x0C` | 4 B | uint32，通道数 |
| `0x10` | 4 B | uint32，每通道头部长度（RG03 为 140） |
| `0x1C` | 4 B | uint32，每通道采样点数 |
| `0x30` | 8 B | float64，`x_increment`，采样间隔（秒/点） |
| `0x00`–`0xFF` | ASCII | 型号、序列号、日期、时间等元信息（用正则提取） |

**通道块**

从 `0x80` 开始扫描 `CH1\0` … `CH4\0` 标记。每个通道的数据起点 = 标记位置 + 每通道头部长度，长度 = 每通道点数 × 4 字节，float32 小端。

**格式代号对应机型**

| 代号 | 机型 |
| --- | --- |
| `RG01` | DS1000Z / MSO5000 / DS7000 |
| `RG03` | DHO800 / DHO1000 |
| `RG02` | DS8000 / MSO8000 |

## 已知限制

说清楚比藏着好：

- **只认 `CH1`–`CH4`**：通道标记的扫描范围就到这里，超过 4 通道的文件看不到 CH5 及以后。
- **幅值绝对值 > 100 的点会被置为 `NaN`**：这是有意为之 —— 通道块之间的头部/尾部 ASCII 字节经常会被当成 float32 电压读出来（`'C'` = `0x43` 会变成 ~70），不裁掉的话波形末端会出现莫名其妙的尖峰。如果你测的是高压信号（> 100 V），这里要改一下。
- **不做垂直偏移和探头倍率换算**：显示的就是文件里存的原始电压值。
- **只支持 `.bin`**：CSV、RTF 以及其它导出格式都没有做。
- **时间轴是相对时间**：可见窗口最左端恒为 0，不是整段记录里的绝对位置。

```
rigol-waveform-viewer/
├── index.html            # 整个应用（解析 + 渲染 + 交互）
├── tools/
```

## 开发

改完直接刷新浏览器即可，没有构建步骤。

```bash
npm run sample     # 生成示例波形
npm run verify     # 校验示例波形能被解析器正确读取
```
